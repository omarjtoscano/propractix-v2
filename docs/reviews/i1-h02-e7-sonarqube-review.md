Java de E6, sin detalle de regla. Se utilizó el analizador **ya instalado** de
SonarQube for IDE 6.2.0 mediante LSP, en modo standalone, con caché aislada en
`/tmp` y configuración predeterminada sin desactivar reglas. No se instaló
SonarQube ni se añadieron dependencias, configuración de proyecto, workflows
o gates. El adaptador temporal de LSP y sus logs no forman parte del producto.
El primer intento dentro del sandbox no pudo abrir sockets locales; las dos
pasadas válidas se ejecutaron con acceso local permitido y terminaron sin
fallos de análisis. Los procesos temporales se terminaron al finalizar.

Motor: Language Server 6.2.0.79823; analizador JavaScript/TypeScript
14.3.0.46350 y Java 8.44.0.48651. Se abrieron los 37 archivos TS/TSX/MJS/CSS
modificados por E7 (incluidos 16 generados) y el codec Java activo en el IDE:
**38 archivos**. La lista exacta y los diagnósticos, con regla, mensaje, rango,
impacto, decisión y tratamiento individual, están en
[i1-h02-e7-sonarqube-findings.json](i1-h02-e7-sonarqube-findings.json).
Se tomó la última publicación de diagnósticos por archivo; las notificaciones
repetidas de LSP no se cuentan como hallazgos nuevos.

Esta evidencia es **análisis local de IDE**, no resultado de SonarQube Server,
Cloud ni certificación de Quality Gate. No cubre todos los lenguajes del repo
ni sustituye la verificación del Product Owner. CI, Trivy, Build OCI y el
resultado remoto de SonarQube, cuando esté disponible, quedan pendientes de
su verificación; el agente no espera ni supervisa esos checks.

## Resultado y decisiones

Primera pasada: **46 hallazgos**: 18 en código propio de E7, 27 en código
generado y 1 previo de E6. Segunda pasada sobre el árbol corregido:
**29 hallazgos**; los **17 corregidos** han desaparecido. Quedan 1 aviso propio
justificado, 9 avisos generados justificados por su contexto, 18 pendientes de
una corrección revisada del generador y 1 ajeno al alcance. No se presenta el
análisis como verde ni se cambian reglas para reducir el recuento.

Las correcciones propias se limitan a readonly, Number.NaN, precedencia de
estados sin ternarios anidados, output nativo para estados y ejecución del CLI
npm actual mediante el ejecutable absoluto de Node. Las lecturas independientes
del snapshot se paralelizan; las dos generaciones siguen siendo secuenciales.

S1082 se justifica con el [patrón de combobox WAI-ARIA APG](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/):
el foco DOM permanece en el input, el teclado selecciona mediante
aria-activedescendant y las opciones no son paradas de Tab. Las pruebas
verifican flechas, Intro, Escape, foco, ARIA y el mismo UUID que la selección
por puntero. Añadir un listener vacío o hacer tabbable cada opción no aporta
la accesibilidad que pide el patrón. La regla sigue activa y el aviso se conserva.

Las líneas de las tablas son las del commit base, para mantener trazabilidad.
El JSON también registra las ubicaciones restantes tras la corrección.
Los identificadores SQ-xx pertenecen a esta revisión; no son claves de issues
de un servidor SonarQube.
